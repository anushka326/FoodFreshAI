# FoodFresh AI — Food Recognition V3 Dataset Area

This directory contains the prepared dataset manifests, metadata, and configuration for Food Recognition V3.

## Structure
- `manifests/`: Standardized CSV manifests for train, validation, benchmark test, and real-world test.
- `metadata/`: Supporting cross-dataset mappings and class inventories.
- `validation/`: Dataset validation reports and integrity checks.
- `label_map.json`: Authoritative 24-class vocabulary mapping.
- `dataset_config.json`: Comprehensive pipeline configuration.
