# Landing Page Variations

## Overview
This folder documents the two Landing Page designs exported from Google Stitch:
1. `landing-page-with-splash.html`: Contains the initial entrance animation with pulsing logo, ripple effects, progress indicator, and skip control.
2. `landing-page-standard.html`: Contains the clean, direct landing view without the splash overlay.

## Key Design Tokens Preserved
- Palette: Primary `#013a13`, Primary Container `#1e5128`, Secondary `#006e1c`, Background `#ebffe5`.
- Typography: Plus Jakarta Sans with defined typographic step scale.
- Components:
  - Hero with CTA pill buttons
  - Problem Lifecycle vertical path (Buy -> Store -> Forget/Unsure -> Quality Declines -> Food Waste)
  - Core Features & Priority preview (Apple A [Eat First], Banana B [Next], Apple C [Can Wait])
  - 4-Step Process: Upload -> Identify -> Understand -> Decide
  - Live preview card with Gala Apple 92% freshness progress bar
  - Social impact progression strip
  - Coming Soon roadmap cards
  - "Did You Know?" fact tiles
